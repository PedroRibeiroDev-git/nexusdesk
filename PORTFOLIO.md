## NexusDesk — Service Desk Full Stack

Plataforma de gerenciamento de chamados desenvolvida com React, TypeScript, Java, Spring Boot e PostgreSQL. O sistema possui autenticação JWT, controle de acesso por perfis, dashboard, filtros e paginação, histórico de auditoria, notas internas, atribuição de chamados, administração de usuários e ambiente completo com Docker Compose.

**Destaques técnicos:** arquitetura REST, Spring Security, RBAC, JPA/Hibernate, Flyway, optimistic locking, validação, tratamento centralizado de erros, React Router, UI responsiva e CI com GitHub Actions.

**Stack:** Java 21 · Spring Boot · Spring Security · PostgreSQL · React · TypeScript · Docker

## Descrição curta para card

Sistema full stack de Service Desk com autenticação JWT, perfis Cliente/Agente/Admin, gerenciamento completo de chamados, auditoria, dashboard e Docker.
