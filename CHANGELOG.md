# Changelog

## 1.0.0 — versão de portfólio

- autenticação JWT e RBAC com Cliente, Agente e Administrador;
- gestão de chamados com categorias, prioridade, status e atribuição;
- comentários públicos e notas internas;
- histórico de auditoria;
- dashboard por perfil;
- administração de usuários;
- migrations Flyway e PostgreSQL;
- Docker Compose com health checks;
- frontend React + TypeScript servido por Nginx;
- workflow de CI com GitHub Actions;
- documentação de API, arquitetura e validação funcional;
- screenshots reais da aplicação.
